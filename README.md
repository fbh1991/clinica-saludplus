
# Clínica SaludPlus

Aplicación web para la gestión de una clínica médica,
desarrollada con PHP, MySQL, HTML, CSS y JavaScript.

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Gestión de perfiles.
- Solicitud y administración de citas médicas.
- Publicación y consulta de noticias.
- Panel de administración.
- Gestión de usuarios y roles.

## Tecnologías utilizadas

- PHP 8
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- PDO para conexión con la base de datos

## Instalación local

1. Instalar XAMPP.
2. Copiar el proyecto dentro de htdocs.
3. Crear la base de datos clinical_fbh.
4. Importar el archivo SQL.
5. Configurar includes/.env.php.
6. Iniciar Apache y MySQL.
7. Abrir el proyecto desde localhost.
